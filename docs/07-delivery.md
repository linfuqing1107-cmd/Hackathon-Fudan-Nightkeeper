## 2. 建议节奏

两名开发者且能获得产品/临床及时评审的情况下，纯模拟原型估计4至6周：第1周T00-T02，第2周T03-T04，第3周T05-T06，第4周T07-T08，余下为修复和T09。此为排期假设，不是固定承诺；单人、真实硬件和伦理接入另估。

每周验收运行流程，不只审截图。风险排序：授权隔离、数据口径、任务并发、缺失误判优先于AI文案和视觉润色。

## 3. Definition of Ready / Done

Ready：工作包有明确需求ID、接口形状、验收案例、依赖已满足；涉及临床的新行为不默认通过。

Done：代码审查完成，自动化测试通过，错误与空状态覆盖，无真实数据/密钥，需求追踪更新，已知限制有记录。工程完成不等于临床有效。
