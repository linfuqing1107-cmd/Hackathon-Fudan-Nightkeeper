## 3. 演示验收脚本

1. 管理员重置当前空间，记录seed和时钟，登录分配医护。
2. 检查三人列表：S01无任务，S02两类变化，S03质量任务。
3. 打开S02，核对三日睡眠300、基线480、差值-180及精力4，不显示疾病诊断。
4. 认领CHANGE_REVIEW，创建联系记录，生成摘要草稿，显示来源模式与证据。
5. 进入等待回访，再恢复并关闭，检查审计和任务历史；服药任务仍独立开放。
6. 打开S03，证明空白不等于0，恢复模拟同步后任务仍需人工关闭。
7. 切患者身份提交一条报告，切回工作台确认更新；尝试越权资源应被拒绝。
