## ADR-08：嵌入式PostgreSQL与聚合存储

当前机器Docker daemon未运行。为了本地原型可启动，采用PGlite（嵌入式PostgreSQL）和一个web进程，不要求Docker。每个浏览器空间的领域状态存储于workspaces.state JSONB，任务关系投影到task_constraints以执行开放任务唯一约束。写事务锁空间行，原型阶段串行化同空间写入。

此选择不是完整关系化迁移，也不是多进程生产方案。同一DATA_DIR只能由一个Node进程持有。未来真实部署需关系化表、索引、迁移版本、PostgreSQL服务、容量测试和备份恢复验证。

## ADR-09：同步规则和模板摘要

演示数据量有限，报告保存及规则执行在同一个事务内完成，没有独立worker或异步job。模板摘要也同步200返回，界面始终标注TEMPLATE/非AI。未接入外部模型，不宣称模型超时、模型注入防护或AI语义校验已验证。

## 接口差异

- /view提供角色过滤的固定小队列快照，便于一次刷新保持一致。
- /demo/session用于本地引导/身份切换，没有业务幂等缓存；已登录切换需CSRF。
- PUT反馈也要求Idempotency-Key，另外检查expectedVersion。
- /tasks/:id/summary-review替代独立summary审阅路由，使用任务version。
- /demo/recover是管理员模拟同步入口；会检查WEARABLE授权，不是真实设备接口。
- 当前每会话180请求/分钟粗粒度限流；公开部署需分类限流和认证。
- 中国时区固定；夏令时、跨区旅行场景未支持。
